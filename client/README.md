# Paper Tracker - Client

This is the frontend application for the Paper Tracker system.

## Tech Stack
- **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS**

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Environment Variables
Create a `.env.local` file for API URLs if needed:
```env
NEXT_PUBLIC_API_URL=http://localhost:4000/api
```
