# Database Schema (SQLite)

The database is managed using Prisma. Below are the core models.

## Models

### User
- `id`: Integer (Primary Key, Autoincrement)
- `email`: String (Unique)
- `passwordHash`: String
- `createdAt`: DateTime

### Topic
- `id`: Integer (Primary Key, Autoincrement)
- `name`: String
- `keywords`: String (Comma-separated keywords used for arXiv searching)
- `userId`: Integer (Foreign Key to User)
- `createdAt`: DateTime

### Paper
- `id`: Integer (Primary Key, Autoincrement)
- `arxivId`: String (Unique)
- `title`: String
- `abstract`: String
- `summary`: String (Generated by AI)
- `authors`: String (JSON string or comma-separated list)
- `publishedDate`: DateTime
- `url`: String
- `score`: Float (Optional, AI-calculated impact score)
- `createdAt`: DateTime

### PaperTopic (Many-to-Many)
- `paperId`: Integer (Foreign Key to Paper)
- `topicId`: Integer (Foreign Key to Topic)

### Favorite
- `userId`: Integer (Foreign Key to User)
- `paperId`: Integer (Foreign Key to Paper)
- `createdAt`: DateTime
