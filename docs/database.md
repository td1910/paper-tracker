# Database Schema (SQLite)

The database is managed using Prisma. Below are the core models.

## Models

### User
- `id`: String (Primary Key, UUID)
- `email`: String (Unique)
- `passwordHash`: String
- `createdAt`: DateTime
- `userTopics`: UserTopic[]
- `favorites`: Favorite[]
- `notifications`: Notification[]

### Topic
- `id`: Integer (Primary Key, Autoincrement)
- `name`: String (Unique)
- `keywords`: String (Comma-separated keywords used for arXiv searching)
- `description`: String (Optional)
- `papers`: PaperTopic[]
- `followers`: UserTopic[]
- `createdAt`: DateTime

### Notification
- `id`: Integer (Primary Key, Autoincrement)
- `message`: String
- `isRead`: Boolean
- `fkUserId`: String (Foreign Key to User)
- `createdAt`: DateTime

### UserTopic (Topic subscriptions)
- `id`: Integer (Primary Key, Autoincrement)
- `fkUserId`: String (Foreign Key to User)
- `fkTopicId`: Integer (Foreign Key to Topic)
- `keywords`: String (Optional, extra personal keywords)
- `createdAt`: DateTime
- Unique constraint: `fkUserId + fkTopicId`

### Paper
- `id`: Integer (Primary Key, Autoincrement)
- `arxivId`: String (Unique)
- `title`: String
- `abstract`: String
- `summary`: String (Optional, generated by AI or fallback text)
- `authors`: String
- `publishedDate`: DateTime
- `url`: String
- `score`: Float (Optional, legacy impact score)
- `aiSummary`: String (Optional)
- `readabilityScore`: Integer (Optional)
- `aiStatus`: String (Defaults to `PENDING`)
- `topics`: PaperTopic[]
- `favorites`: Favorite[]
- `createdAt`: DateTime

### PaperTopic (Many-to-Many)
- `fkPaperId`: Integer (Foreign Key to Paper)
- `fkTopicId`: Integer (Foreign Key to Topic)
- Composite primary key: `fkPaperId + fkTopicId`

### Favorite
- `fkUserId`: String (Foreign Key to User)
- `fkPaperId`: Integer (Foreign Key to Paper)
- `createdAt`: DateTime
- Composite primary key: `fkUserId + fkPaperId`
